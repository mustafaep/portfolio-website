## Ne olduğu

SoccerApp, ASP.NET Core 8 ile yazılmış bir futbol takımı yönetim paneli. Bursa'daki BRM Bilgisayar stajımın kapanış projesiydi — İMEP mesleki eğitim programı ve yaz stajı; 20 kişilik bir geliştirme ekibi içinde altı ay.

## Bağlam

.NET tarafında asıl olarak bu stajda çalıştım: .NET 8 ile masaüstü uygulamaları, ASP.NET Core ile web uygulamaları ve Microsoft SQL Server üzerinde Entity Framework. Katmanlı kurumsal mimariyle ve gerçek bir code review süreciyle de ilk kez burada karşılaştım; servisleri bugün nasıl kurguladığımı bu deneyim şekillendirdi.

Kaynak kodu [GitHub'da](https://github.com/mustafaep/SoccerApp).
